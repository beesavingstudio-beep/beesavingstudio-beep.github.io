# Beestudio Digital

Website statis siap digunakan di GitHub Pages.

## File utama

- `index.html` — isi halaman website
- `styles.css` — tampilan dan desain responsif
- `bee-premium-3d.png` — logo/maskot lebah 3D premium

Unggah ketiga file tersebut ke bagian utama repositori GitHub. Setelah GitHub Pages diaktifkan dari branch `main` dan folder `/root`, website akan tampil otomatis.
